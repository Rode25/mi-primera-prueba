# Reporte de Unidades y Ramos de Seguros (Marzo 2026)

Este repositorio contiene el archivo `.pbix` de Power BI con el análisis de mercado de seguros, distribución por ramos y comparativa de compañías.

## 📊 Descripción del Dashboard

El reporte interactivo incluye las siguientes páginas y visualizaciones clave:

* **Métricas Principales (KPIs):** Mercado Total (4.53 mill.), Total Vida (2.5 mill.), Total Generales (1.98 mill.) y Total Compañías (23).
* **Distribución por Ramos:** Análisis mediante gráfico de pastel y barras para identificar la participación por segmento (Automóvil, Salud, Incendio, etc.).
* **Ranking y Comparativa:** Proporción de Vida vs. Generales por compañía de seguros.
